# Airline Reservations

**English** | [Türkçe](README.tr.md)

A desktop flight booking app written in Java and JavaFX: passengers search flights, pick their seats on a visual seat map and manage their bookings; staff manage flights and passenger lists. Data is stored in SQLite.

> Work in progress.

## Planned Features (MVP)

- Flight search by route and date, with prices that rise as the flight fills up
- Booking for up to 6 passengers with a visual seat map (business / economy, extra legroom seats)
- Booking code (PNR) and PDF e-ticket
- Manage booking with booking code + last name: change seat, online check-in with PDF boarding pass, cancellation with a refund rule
- Staff panel (Argon2id password): dashboard, flight list, new flight, delay / cancel flight, passenger list
- Turkish and English, light and dark theme, Windows installer

## Future Plans

- Round-trip and multi-city search
- Baggage and meal add-ons
- Online payment simulation
